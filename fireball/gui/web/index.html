Resumo, nome e tags

O mesmo provedor escreve as três coisas de uma vez, a partir da transcrição. claude_code usa o Claude Code instalado na máquina — não pede chave de API, mas precisa dele autenticado (claude no PATH, com login feito). openai_api é qualquer API compatível com OpenAI: a da OpenAI, OpenRouter, Groq, Ollama, llama.cpp, LM Studio — você diz a URL, a chave e o modelo.

Provedor
URL da API
A base, normalmente terminada em /v1 — o /chat/completions entra sozinho. Servidor local costuma ser http://localhost:11434/v1 (Ollama) ou :1234/v1 (LM Studio).
Chave
Guardada em ~/.fireball/settings.json, com permissão 600. Deixe vazia para usar FIREBALL_OPENAI_API_KEY do ambiente — ou quando o servidor é local e não pede chave.
Modelo
O id exato como o servidor o chama.

Roda ao fim da gravação e de novo quando a transcrição final fica pronta (ela reescreve a transcrição, e o resumo antigo passa a ser sobre um texto que não existe mais). É o que faz uma reunião sem nome ganhar um sem ninguém pedir. Desligado, o resumo só sai no botão Gerar. Reunião simulada (--fake) nunca gera sozinha — ela existe pra testar o pipeline sem gastar API.

Prompts do resumo

Um prompt diz o que o resumo deve conter e em que forma. O resto do pedido é sempre o mesmo e não se edita: de onde vem a transcrição, o que significam os os rótulos de falante, e o JSON com title, tags e summary — é isso que faz qualquer prompt continuar rendendo nome e tags para a reunião.

Padrão
Vale para reunião que ainda não foi resumida. Depois de resumida, ela lembra o prompt que usou — regerar e o resumo automático pós-finalize repetem a escolha em vez de trocar de formato no meio do caminho.
Provedor de agenda

Lê os próximos eventos e deixa iniciar a reunião a partir de um — já com nome, local, descrição e convidados, que também viram contexto do resumo. gog usa o gogcli instalado na máquina (já autenticado); o Fireball não guarda token nenhum. Desligado é o padrão: a home mostra o estado vazio e nenhum binário é chamado.

Provedor
Conta do gog
E-mail passado como --account. Deixe vazio se o gog já tem uma conta só autenticada. Token morto: rode gog auth add <email>.

Escreva como se continuasse a frase "e o resumo deve ficar assim". Peça summary em markdown; um prompt que peça lista também funciona. O resto do pedido — os falantes e o JSON com title, tags e summary — entra sozinho, e não se edita aqui.

Dar nome à voz

Ao salvar, você confirma manualmente quem falou. O Fireball extrai a voz dos trechos desta reunião e guarda apenas embeddings locais para reconhecê-la no futuro.
